# Papers I’ve Read

This repository contains my personal notes on machine learning, computer vision, transformers, graph theory, and optimization.  
The goal is to **track papers I find interesting, summarize their key ideas, and retain them for future reference**.

## Structure

- `vision/` - Computer vision papers
- `optimization/` - Optimizers and training methods
- `graphs/` - Graph neural networks and spectral methods

## How to read my notes

Each paper has its own Markdown file containing:

- Paper link
- Why it matters
- Key ideas
- Core equations
- Intuition
- Connections to other concepts
